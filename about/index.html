about

i'm praveen sharma, alias ITACHI — web security researcher, linux enthusiast, and aosp developer based in India 🇮🇳.

i spend most of my time breaking web applications with Burp Suite, ricing Arch Linux with Hyprland, and tinkering with AOSP internals. i currently run Arch Linux on my main machine with MistOs. can't decide what to do, so i do everything.

i'm into low-level programming — C and C++ mostly. i write Python for tooling and scripting, Go for anything that needs to be fast, and JavaScript when i have no choice.

i'm a big advocate for open source. linux, free software, the whole deal. if it has source code, i want to read it. if it's broken, i want to fix it.

when i'm not at a terminal, i'm probably listening to music or trying to figure out what my next project should be.
