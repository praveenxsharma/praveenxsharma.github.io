Hello World

26/02/26 · ~200 words · 1 min read
misc

first post. not entirely sure what i'm going to write about yet, but that's kind of the point. this is my space to dump thoughts, writeups, and notes — mostly around security, linux, and whatever i'm poking at on a given week.

Why

i've been meaning to do this for a while. there's a lot of things i figure out by breaking stuff or just spending too many hours in a terminal, and most of it lives in my head or scattered across notes. writing it down forces me to actually understand it properly.

expect writeups, ctf notes, linux things, maybe some aosp stuff. no promises on frequency.

Setup

the site is plain HTML and CSS. no frameworks, no build step, no javascript nonsense for something that doesn't need it. just files. runs on GitHub Pages. 

praveenxsharma.github.io/
  index.html
  about/
  blog/
    _template/   <-- copy this for every new post
    hello-world/
  assets/
    css/
    js/

to add a new post: copy blog/_template/index.html into a new folder, fill in the content, add a card to blog/index.html. that's it.
